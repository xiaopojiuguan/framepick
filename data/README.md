# 数据说明

本仓库**不包含**任何数据集文件，原因有三：体积、版权、以及课程要求里明确需要自建一组数据。
下面是本项目规划使用的数据来源，以及自采数据的组织方式。

## 1. 公开数据集（用于美学模型微调 / 评测）

| 数据集 | 规模 | 标注 | 用途 | 获取 |
| --- | --- | --- | --- | --- |
| **ATF Photo Series** (Chang et al., SIGGRAPH 2016) | 15,545 张 / 5,953 组 | 组内成对偏好 | **最贴近本任务**：同场景连拍组 | [项目主页](https://gfx.cs.princeton.edu/pubs/Chang_2016_ATF/index.php) |
| AVA (Murray et al., CVPR 2012) | 255,530 张 | 1~10 美学分分布 | 训练 NIMA / 美学头 | [GitHub](https://github.com/imfing/ava_downloader) |
| TAD66K (He et al., CVPR 2022) | 66,000 张 | 主题+美学分 | 检验跨主题泛化 | 论文主页 |
| AADB (Kong et al., ECCV 2016) | 10,000 张 | 5 人打分 + 11 属性 | 属性级评测 | 项目主页 |
| SPAQ (Fang et al., CVPR 2020) | 11,125 张 | 手机拍摄 MOS | 检验"手机随手拍"域偏移 | 项目主页 |

> 只做**评测**、不做训练时，用 AVA 的子集 + ATF 的组结构即可，不需要下载全部。

## 2. 自建 SeriesSet（本项目主张的数据）

公开数据集中"同一场景连续拍摄"的组很少，且不含中文场景（校园、街拍、夜宵摊……）。
所以我们自建：

```
data/series/
  s01_操场连拍/          # 一组 = 一个目录
    IMG_0001.jpg
    IMG_0002.jpg
    ...
  s02_花海人像/
  ...
```

采集要求：

- **规模**：≥ 30 组，每组 5~20 张，总计 ≥ 300 张；
- **设备**：至少 2 台手机 + 1 台相机，覆盖不同厂商色调；
- **场景**：人像 8 组、风光 8 组、街拍 8 组、静物/食物 6 组；
- **变量**：每组刻意包含构图偏移、曝光抖动、轻微失焦、主体移动（与真实连拍一致）；
- **隐私**：人像需被摄者同意；入库前统一去除 EXIF 中的 GPS 信息。

标注（`tools/label_tool.py`）：

1. 标注员对每组给出**完整排序**（1 = 最值得保留）；
2. 至少 2 人独立标注，计算 Kendall τ 与 Cohen's κ，低于 0.6 的组进入仲裁；
3. 组内 20% 做重复标注，用于估计标注噪声上限。

## 3. 目录约定

```
data/
  sample/          # 合成演示数据（脚本生成，可入库）
  series/          # 自建真实数据（不入库，.gitignore 已排除）
  labels.csv       # 标注结果（不入库）
```
